# AI外贸管理系统

AI外贸管理系统 is a foreign trade lead generation and CRM admin system built with Vue 3, Vite, TypeScript, Pinia, Vue Router, Naive UI, and NestJS.

## Local Development

```bash
pnpm install
pnpm dev
```

For backend services and database setup, refer to the existing environment configuration and Docker Compose file in this project.
